# Portfolio Project 2: Customer Churn Prediction

## Overview
A Machine Learning project focused on predicting customer churn using tabular classification techniques (Logistic Regression / Random Forest).

## Key Features
- Synthetic customer demographic and subscription dataset generator.
- Data preprocessing & feature scaling pipeline.
- Model training, evaluation metrics (Accuracy, Precision, Recall, ROC-AUC).

## How to Run
```bash
python projects/customer-churn/churn_model.py
pytest projects/customer-churn/test_churn_model.py
```
