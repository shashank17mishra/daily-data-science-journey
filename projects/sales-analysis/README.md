# Portfolio Project 1: Sales Data Analysis

## Overview
A comprehensive Data Analysis project that analyzes e-commerce transactional sales data using Pandas, NumPy, SQL, and Data Visualization tools.

## Key Features
- Synthetic sales dataset generation.
- Revenue trends analysis across time windows.
- Product category performance metrics.
- Customer cohort lifetime value (LTV) estimation.

## How to Run
```bash
python projects/sales-analysis/analysis.py
pytest projects/sales-analysis/test_sales_analysis.py
```
