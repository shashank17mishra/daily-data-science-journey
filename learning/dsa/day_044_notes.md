# Day 044: Binary Tree Traversals

## Overview
Implement recursive and iterative binary tree traversals (pre-order, in-order, post-order, and level-order) along with comprehensive pytest unit tests.

## Objectives
- Understand algorithmic mechanics of Binary Tree Traversals.
- Implement iterative and recursive tree traversal patterns.
- Implement unit tests for edge cases.

## Key Concepts
Binary tree traversals form the foundation of tree-based algorithms. Pre-order, in-order, and post-order can be implemented via recursion or explicitly using a stack. Level-order traversal utilizes a queue data structure to visit nodes level by level.
